## 14. La elusión como mercado de dos economías: el paquete abierto y el servicio con SLA

Toda la thread hasta ahora ha medido **insumos** de elusión en unidades monetarias: el captcha a $0.5 — $50 por 1000, el proxy por gigabyte o por IP, el número SMS a céntimos, el correo a precio de lote. La captura del 2026-10-25 de `berstend/puppeteer-extra` no añade ni un precio, pero **cambia la pregunta**: junto a esa capa de compras existe **otra elusión que no se compra, que se instala**, y es un mercado con las dos mismas características de escala —7,4k estrellas, 115 watchers, 783 forks— y una forma de distribución radicalmente distinta.

**El dato de partida es que el captcha, el proxy y la huella del navegador no son solo servicios: son paquetes con número de versión.** La captura permite nombrar **diez paquetes** del ecosistema —`puppeteer-extra`, `puppeteer-extra-plugin`, `puppeteer-extra-plugin-stealth`, `puppeteer-extra-plugin-recaptcha`, `puppeteer-extra-plugin-adblocker`, `puppeteer-extra-plugin-user-data-dir`, `@extra/proxy-router`, `puppeteer-extra-plugin-anonymize-ua`, `puppeteer-extra-plugin-devtools` y `extract-stealth-evasions`— obtenidos del badge de descargas de npm y del mensaje del commit de publicación, **no de un catálogo del README**, que no existe ([[2026-1026-puppeteer-extra-catalogo-de-plugins-numerados-en-la-captura]]). Seis de ellos llevan versión explícita en ese commit: `puppeteer-extra@3.3.6`, `puppeteer-extra-plugin-recaptcha@3.6.8`, `@extra/proxy-router@3.1.6`, `extract-stealth-evasions@2.7.3`, `puppeteer-extra-plugin-anonymize-ua@2.4.6` y `puppeteer-extra-plugin-devtools@2.4.6` ([[2026-1026-puppeteer-extra-seis-paquetes-y-esus-versiones-en-el-commit-de-publicacion]]).

**Los tres paquetes que la thread tenía como partidas tienen aquí su equivalente abierto.** El captcha es `puppeteer-extra-plugin-recaptcha@3.6.8`. El proxy es `@extra/proxy-router@3.1.6`, añadido el **8 de agosto de 2022** con el commit "feat: Add plugin proxy-router (#693)" — es decir, **el enrutado de IPs, que la §8 describe como geometría de sesión a resolver, existe como plugin publicado y versionado** ([[2026-1026-puppeteer-extra-plugin-proxy-router-anadido-en-agosto-de-2022]]). Y la huella del navegador no es un bloque sino **un catálogo de evasions granulares**: cada evasión es un artefacto con nombre, ruta y **test propio** —el README documenta `cd packages/puppeteer-extra-plugin-stealth` y `yarn ava -v ./evasions/user-agent-override/index.test.js`— y existe además un sub-paquete aparte, `extract-stealth-evasions@2.7.3` ([[2026-1026-puppeteer-extra-stealth-y-extract-stealth-evasions-como-paquetes-separados]]).

**La extensión de superficie es lo que hace esta fuente irreemplazable en el thread.** La API de extensión es una **clase base publicada** (`PuppeteerExtraPlugin`, en el paquete `packages/puppeteer-extra-plugin`), con documentación propia y un plugin mínimo de ejemplo (`anonymize-ua`) ([[2026-1026-puppeteer-extra-api-de-plugins-con-clase-base-puppeteerextraplugin]]). Y el monorepo mantiene **dos líneas de framework bajo la misma API** —Puppeteer y Playwright—, esta última señalada como añadida "recently" ([[2026-1026-puppeteer-extra-playwright-extra-como-soporte-nuevo-en-el-mismo-monorepo]]). Playwright es exactamente el nombre bajo el que la thread ya había encontrado Playwright dos veces, y las dos veces en clave comercial: como integración de agente en la home de CapSolver ("01 AGENTS — AI agent automation") y como integración incluida en cada plan de Decodo. **La superficie comercial de evasión y la superficie de código abierto de evasión comparten nombre de framework** ([[2026-1026-puppeteer-extra-topics-que-declaran-recaptcha-stealth-y-user-preferences]]).

**La consecuencia sobre el modelo de coste es de una sola frase: hay dos economías y el precio del catálogo mide solo una de ellas.** La economía de servicios —captcha a $0.001, proxy por gigabyte, VPN a €3,49/mes, resolución con SLA y uptime publicado— **es la única que la tabla de coste por insumo de la §7 puede cotizar**. La economía abierta —licencia MIT, plugins con versión, coste marginal cero por captcha resuelto y coste de mantenimiento propio— **no tiene ninguna línea en esa tabla porque no tiene precio**. Y la comparación no es abstracta: con 7,4k estrellas frente a las **810 que suman los 14 repositorios** de la consulta de "chatgpt account creator", el framework de evasión es **un orden de magnitud más popular que la suma de los scripts de alta que el thread tenía inventariados** —lo que reutiliza la gente es el framework, no el bot ([[2026-1026-puppeteer-extra-604-commits-559-tags-y-ultimo-commit-en-marzo-de-2023]]).

**Un dato de la misma fuente cambia la lectura del corpus de repos.** El ratio forks/estrellas de este proyecto es de **0,11** (783 sobre 7.4k), cuando en los tres repositorios con comunidad de la consulta de GitHub era de **0,51**, **0,50** y **0,27** ([[2026-1026-puppeteer-extra-783-forks-sobre-7-4k-estrellas-un-ratio-de-0-11]]). La §7.5 leía ese ratio como la señal de que "el uso dominante de estas herramientas es copiar y modificar, no instalar y mantener". Con este dato se puede afinar la regla: **ratio alto + sin versionado = plantilla que se copia; ratio bajo + versionado por paquete = proyecto que se instala y se fija**. Es la misma variable de decisión que separa el `git clone` + `go run` desde `main` de `verssache/chatgpt-creator` (4 commits, 0 tags, 0 releases) del `npm install` con versión fijada de este monorepo (604 commits, 559 tags) ([[2026-1026-puppeteer-extra-flujo-de-publicacion-por-lerna-con-npm-y-no-yarn]]).

**Y una advertencia de frescura, que es la parte incómoda.** El proyecto está **congelado desde el 1 de marzo de 2023** —commit "Publish" `39248f1`, el último de la cabecera— tres años y medio antes de la captura; el README no se toca desde el **3 de julio de 2022** y `package.json` desde el **21 de septiembre de 2021**, con un mensaje de commit que habla de "Support old and new puppeteer types" y de "ci: Update puppeteer version matrix" ([[2026-1026-puppeteer-extra-604-commits-559-tags-y-ultimo-commit-en-marzo-de-2023]]). La sección "Releases" de la página aparece **vacía**. Es decir: **la alternativa abierta a la elusión de pago es un framework con ciclo de release real pero detenido**, y su ventaja operativa —poder fijar una versión y auditar el artefacto— sigue siendo real, mientras que su mantenimiento no existe. La thread **no puede** presentar la economía abierta como sustituta de la comercial sin esta fecha al lado ([[2026-1026-puppeteer-extra-prueba-de-un-paquete-local-como-lo-veria-el-registry]]).

**Lo que la captura deja deliberadamente sin contestar.** El README raíz **no contiene instrucciones de instalación como dependencia de consumo ni un catálogo de plugins**: es la documentación de mantenimiento del monorepo, y remite la documentación del producto al paquete `packages/puppeteer-extra`, que no está capturado ([[2026-1026-puppeteer-extra-readme-de-monorepo-sin-instalacion-ni-catalogo-de-plugins]]). El vault **no ha clonado ni ejecutado el repositorio**, no ha leído la clase base, no sabe qué hace el plugin de recaptcha ni qué evasions existen, y no conoce la matriz de versiones de Puppeteer soportada. La lista de diez paquetes es una **transcripción literal** del badge de npm y del mensaje de commit, no un inventario auditado.

45. **El captcha no es siempre una partida: existe una vía publicada con licencia abierta, y por tanto la tabla de precios mide una elección de arquitectura y no una necesidad.** La §7 sostiene que "el captcha es la partida más barata y la más fácil de cotizar" y la fricción 38 añade que ya hay una tercera vía (internalizar el navegador con Chromium/Xvfb) cuya aritmética es incompatible con la del catálogo. Esta captura añade una **cuarta vía, que es commodity de código abierto**: existe un `puppeteer-extra-plugin-recaptcha@3.6.8` publicado con su propio número de versión ([[2026-1026-puppeteer-extra-catalogo-de-plugins-numerados-en-la-captura]], [[2026-1026-puppeteer-extra-seis-paquetes-y-esus-versiones-en-el-commit-de-publicacion]]). Si esa vía cubre los tipos que necesita el destino, el captcha deja de ser una partida y **el rango de $0.5 a $50 por 1000 pasa a medir el coste de una decisión de arquitectura**. Las dos cosas no pueden ser simultáneamente la base de una decisión de coste: o el captcha es siempre una commodity de mercado con precio cotizable, o hay al menos una ruta donde su coste marginal es cero y el precio del catálogo es irrelevante. Marcado para juicio humano, no auto-resuelto: **la captura no documenta qué hace el plugin de recaptcha** —ni qué tipos resuelve, ni si usa un solver de pago por debajo, ni su tasa de éxito—, así que el vault no puede afirmar que la vía abierta cubra los mismos casos que el catálogo.

46. **"La huella del cliente no se compra en ninguna parte" es una afirmación sobre un nivel de señal, y el nivel del navegador es un nivel distinto.** La §11 sostiene que "la capa dominante de un flujo de alta contra OpenAI no es una compra, es una construcción" y que "el fingerprint no está en ningún catálogo", con el TLS fingerprinting con perfiles Chrome aleatorizados, el token sentinel y las cabeceras de traza Datadog como pruebas ([[2026-1024-chatgpt-creator-tls-fingerprinting-con-perfiles-chrome-aleatorios]]). El primer nivel de esa afirmación **sigue en pie**: el cliente HTTP con perfiles TLS aleatorizados no se compra en ninguna parte y este framework no lo vende. Pero el segundo nivel es otro: existe un framework MIT que publica **las evasions como piezas granulares y testeadas**, con un test por evasión (`./evasions/user-agent-override/index.test.js`) y un sub-paquete de evasions con versión propia (`extract-stealth-evasions@2.7.3`) ([[2026-1026-puppeteer-extra-stealth-y-extract-stealth-evasions-como-paquetes-separados]]). No puede ser verdad a la vez que toda señal de detección hay que construirla siempre y que hay al menos un nivel en el que es un paquete instalado. Marcado para juicio humano, no auto-resuelto: **la captura no enumera qué evasions existen** ni su cobertura de señales, y la granularidad de una suite de tests no equivale a cobertura funcional.
