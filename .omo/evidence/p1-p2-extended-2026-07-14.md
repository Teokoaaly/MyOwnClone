## Detalle

### P1.2 — Audit-trail cableado (C-03, C-16)

**Antes:** `audit_trail.py::log_audit_action` existía pero **nunca se invocaba**. 0 endpoints admin tenían audit logging. Además, `_ensure_table()` creaba `audit_log` via DDL runtime (con race condition en cold start entre workers).

**Después:**
- **Migración Alembic `2026_07_14_0002_add_audit_log_table.py`** crea `audit_log` con índices (`user_id`, `tenant_id`, `action`, `timestamp`). DDL en la cadena de migraciones, fuera del request path.
- **`audit_trail.py`** simplificado: eliminado `_ensure_table` y `_table_created`. `log_audit_action` ahora solo hace INSERT (no DDL).
- **`@audit_action` aplicado en 5 endpoints admin críticos:**
  - `admin.tenant.create` (AdminTenantsApi.post)
  - `admin.tenant.update` (AdminTenantDetailApi.put)
  - `admin.tenant.delete` (AdminTenantDetailApi.delete)
  - `admin.impersonate.start` (AdminImpersonateApi.post)
  - `admin.impersonate.stop` (AdminStopImpersonateApi.stop)
- **`fail-open`:** un error de DB durante audit logging NO rompe el request del usuario (traga excepción, loguea).

**Tests:** 8 en `test_p1_audit_trail.py`.

### P1.10.06 — Monitoring perf (MEDIUM)

**Antes:**
- `_check_ollama()` hacía un POST real a `/api/embed` con `mxbai-embed-large` en **cada** health probe → desperdiciaba GPU cada 5-30s sin motivo.
- `proc.cpu_percent(interval=0.1)` bloqueaba 100ms por cada health check.

**Después:**
- `_check_ollama()` solo llama `/api/tags` (suficiente para saber si Ollama responde y qué modelos están cargados).
- `proc.cpu_percent(interval=None)` non-blocking.

**Tests:** 2 en `test_p1_monitoring_perf.py` (incluye parse AST que ignora el docstring para no matchear contra `/api/embed` en comentarios).

### P2.8 — N+1 en CloneConfigListApi (MEDIUM)

**Antes:** `CloneConfigListApi.get` ejecutaba 1 SELECT a `clone_configs` + N SELECTs a `clone_mode_prompts` (uno por clone). Con 30 clones = 31 queries.

**Después:**
- `CloneConfig.mode_prompts: relationship` añadida (lazy-loaded vía `selectinload`).
- `CloneConfigListApi.get` ahora hace `options(selectinload(CloneConfig.mode_prompts))` → 2 queries totales (config + IN-clause).

### P3 — uuidv7 unificado + paginación int-safe (LOW)

**Antes:**
- `models/prompt.py` usaba `__import__("uuid").uuid4().hex` (formato sin dashes, inconsistente con el resto del repo que usa `uuidv7()`).
- `admin_platform._pagination_args` hacía `int(request.args.get("page", 1))` sin try/except → `?page=abc` lanzaba ValueError → 500.

**Después:**
- `Prompt.id` y `PromptVersion.id` ahora usan `str(uuidv7())`.
- `_pagination_args` tiene `_safe_int(name, default, lo, hi)` helper que usa try/except y clampa el rango.
