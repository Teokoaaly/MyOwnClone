Design solutions on Azure by using established patterns and practices. The Azure Architecture Center is a catalog of solution ideas, example workloads, reference architectures, technology decision guides, and architecture guides that help cloud architects and engineers build workloads aligned with the Azure Well-Architected Framework and the Cloud Adoption Framework for Azure.
