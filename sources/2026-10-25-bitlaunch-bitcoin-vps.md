- **What is a VPS?**
A VPS is a virtual machine hosted in the cloud that you can connect to from any device. It allows a user to rent a set portion of a server's resources such as RAM, CPU, and storage, without having to share them with other users.

- **What is a VPS used for?**
You can use your VPS for whatever tasks like you like, but they're most commonly used for hosting and development. You can run a website, for example, host a game server, or create apps. BitLaunch additionally allows you to use your [VPS as a VPN](https://bitlaunch.io/blog/how-to-set-up-a-one-click-wireguard-vpn-with-bitlaunch).

- **What does VPS stand for?**
VPS stands for Virtual Private Server. The "virtual" part indicates that it's using virtualization technology to split a single server into several virtual servers. The "private" part references the fact that your server is reserved only for you, with its own resources and no sharing.

- **How to connect to a VPS?**
The method to connect to a VPS varies depending on the operating of your home computer and the operating system of the VPS you're connecting to. To connect to a Linux VPS from a local Windows machine, you can use a tool [like PuTTy](https://bitlaunch.io/blog/how-to-connect-to-ssh-with-putty/).

Connecting to a Windows VPS requires you to use an RDP app. On Windows this is [built-in](https://bitlaunch.io/blog/connecting-to-a-windows-vps-using-rdp/). On Linux you can use a third-party app called [Remmina](https://remmina.org/). macOS, meanwhile, has a dedicated RDP app from Microsoft in the [App Store](https://apps.apple.com/us/app/microsoft-remote-desktop/id1295203466?mt=12).

- **What is the difference between Bitcoin and Ethereum?**
Bitcoin and Ethereum are the largest and second largest cryptocurrencies, respectively. The two cryptocurrencies are similar in many ways, but there are some key differences. Primarily, it comes down to purpose: Bitcoin was built as a decentralized currency, while Etherum was built as both a currency and a way to enforce so-called "smart contracts" – code that is embedded in a transaction that runs when certain conditions are met.As well as allowing the execution of code, Ethereum has a faster block time than Bitcoin and uses a different algorithm – Ethash, versus Bitcoin's SHA-256. Additionally, while both use the same Proof of Work (PoW) system to validate transactions, Ethereum plans to switch to Proof of Stake (PoS) in 2022. This should be less energy intensive.


Though you could consider these features an advantage for Ethereum, it comes down to use-case and personal preference. Some prefer the high-speed development of Ethereum, while others prefer the slow stability of the world's most popular cryptocurrency: Bitcoin.
