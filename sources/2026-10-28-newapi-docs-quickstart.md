# Quick Start

Deploy New API, configure model channels and tokens, and make your first AI API call.

Copy MarkdownOpen

New API is an open-source AI gateway and model API management system. Follow these steps to go from deployment to application integration.

## [Start using New API](https://docs.newapi.pro/en/docs\#start-using-new-api)

[**1\. Deploy your instance** \\
Start New API with Docker, a management panel, or a cluster.](https://docs.newapi.pro/en/docs/installation) [**2\. Configure a channel** \\
Add a model provider, credentials, and available models.](https://docs.newapi.pro/en/docs/guide/console/channel-management) [**3\. Create an API token** \\
Create a token for your application and call the unified AI API.](https://docs.newapi.pro/en/docs/guide/console/api-token)

## [Choose a deployment method](https://docs.newapi.pro/en/docs\#choose-a-deployment-method)

[**Docker Compose** \\
Run New API alongside services such as MySQL and Redis.](https://docs.newapi.pro/en/docs/installation/deployment-methods/docker-compose-installation) [**Docker single container** \\
Get started with a Docker image for evaluation or small deployments.](https://docs.newapi.pro/en/docs/installation/deployment-methods/docker-installation)

Need a management panel, cluster, or local development environment? See [all deployment methods](https://docs.newapi.pro/en/docs/installation).
