# Azure Architecture Center

Design solutions on Azure by using established patterns and practices. The Azure Architecture Center is a catalog of solution ideas, example workloads, reference architectures, technology decision guides, and architecture guides that help cloud architects and engineers build workloads aligned with the Azure Well-Architected Framework and the Cloud Adoption Framework for Azure.

## Get started

Choose a starting point based on what you need to do.

*   ![Image 10](https://learn.microsoft.com/en-us/media/hubs/shared/get-started-card-icon-orange.svg)  [Browse architectures](https://learn.microsoft.com/en-us/azure/architecture/browse/)
Explore reference architectures, example workloads, and solution ideas.   
*   ![Image 11](https://learn.microsoft.com/en-us/media/hubs/shared/get-started-card-icon-orange.svg)  [Learn the fundamentals](https://learn.microsoft.com/en-us/azure/architecture/guide/)
Understand architecture styles, design principles, and best practices.   
*   ![Image 12](https://learn.microsoft.com/en-us/media/hubs/shared/get-started-card-icon-orange.svg)  [Make technology choices](https://learn.microsoft.com/en-us/azure/architecture/guide/technology-choices/technology-choices-overview)
Compare and select the right Azure services for your workload.   
*   ![Image 13](https://learn.microsoft.com/en-us/media/hubs/shared/get-started-card-icon-orange.svg)  [Apply design patterns](https://learn.microsoft.com/en-us/azure/architecture/patterns/)
Use proven patterns to solve common cloud design challenges.
