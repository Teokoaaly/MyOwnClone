# OpenAI Register

[Permalink: OpenAI Register](https://github.com/911218sky/openai-register#openai-register)

自動化 OpenAI 帳號註冊與 AI API 代理管理工具。

## 功能特點

[Permalink: 功能特點](https://github.com/911218sky/openai-register#%E5%8A%9F%E8%83%BD%E7%89%B9%E9%BB%9E)

### 🤖 OpenAI 自動註冊

[Permalink: 🤖 OpenAI 自動註冊](https://github.com/911218sky/openai-register#-openai-%E8%87%AA%E5%8B%95%E8%A8%BB%E5%86%8A)

- 自動生成隨機郵箱和強密碼
- 支援 Gmail IMAP 自動獲取驗證碼
- 支援代理（HTTP/HTTPS/SOCKS5）
- 批量註冊和循環模式
- 自動保存 Token 和帳號資訊

### 🚀 CLI Proxy API

[Permalink: 🚀 CLI Proxy API](https://github.com/911218sky/openai-register#-cli-proxy-api)

- 支援多種 AI API（Gemini、Claude、Codex、Vertex 等）
- 統一管理多個 API 金鑰
- 智能路由和自動重試
- Docker 一鍵部署

> 基於 [CLIProxyAPIPlus](https://github.com/router-for-me/CLIProxyAPIPlus) 整合

* * *

## 快速開始

[Permalink: 快速開始](https://github.com/911218sky/openai-register#%E5%BF%AB%E9%80%9F%E9%96%8B%E5%A7%8B)

### 安裝

[Permalink: 安裝](https://github.com/911218sky/openai-register#%E5%AE%89%E8%A3%9D)

```
# 克隆專案
git clone https://github.com/911218sky/openai-register.git
cd openai-register

# 安裝依賴
uv sync

# 配置環境變數
cp .env.example .env
# 編輯 .env 填入你的配置
```

### OpenAI 自動註冊

[Permalink: OpenAI 自動註冊](https://github.com/911218sky/openai-register#openai-%E8%87%AA%E5%8B%95%E8%A8%BB%E5%86%8A)

```
# 測試單次註冊
uv run python main.py --once

# 註冊 5 個帳號
uv run python main.py -c 5

# 使用代理註冊 10 個帳號
uv run python main.py -p http://127.0.0.1:7890 -c 10

# 無限循環註冊，間隔 30-120 秒
uv run python main.py -smin 30 -smax 120
```

### CLI Proxy API

[Permalink: CLI Proxy API](https://github.com/911218sky/openai-register#cli-proxy-api)

```
# 進入目錄
cd CLIProxyAPI

# 配置檔案
cp config.example.yaml config.yaml
# 編輯 config.yaml 填入你的 API 金鑰

# 啟動服務
docker-compose up -d

# 訪問服務
# API 端點: http://localhost:8317
# 管理面板: http://localhost:8317/management.html#/login
```

## 命令列參數

[Permalink: 命令列參數](https://github.com/911218sky/openai-register#%E5%91%BD%E4%BB%A4%E5%88%97%E5%8F%83%E6%95%B8)

| 參數 | 說明 | 範例 |
| --- | --- | --- |
| `-c, --count` | 註冊帳號數量（0=無限） | `-c 5` |
| `-p, --proxy` | 代理地址 | `-p http://127.0.0.1:7890` |
| `-smin, --sleep-min` | 最短等待秒數 | `-smin 10` |
| `-smax, --sleep-max` | 最長等待秒數 | `-smax 60` |
| `--once` | 只運行一次（測試用） | `--once` |
| `-d, --debug` | 啟用調試模式 | `-d` |

## 環境變數配置

[Permalink: 環境變數配置](https://github.com/911218sky/openai-register#%E7%92%B0%E5%A2%83%E8%AE%8A%E6%95%B8%E9%85%8D%E7%BD%AE)

建立 `.env` 檔案：

```
# 郵箱配置
MAIL_DOMAIN=gmail.com

# Gmail IMAP（自動獲取驗證碼）
IMAP_SERVER=imap.gmail.com
IMAP_PORT=993
EMAIL_USER=your-email@gmail.com
EMAIL_PASS=your-app-password

# 輸出目錄
TOKEN_OUTPUT_DIR=./tokens

# 網路設定
OPENAI_SSL_VERIFY=1
SKIP_NET_CHECK=0
```

### Gmail 應用程式密碼設定

[Permalink: Gmail 應用程式密碼設定](https://github.com/911218sky/openai-register#gmail-%E6%87%89%E7%94%A8%E7%A8%8B%E5%BC%8F%E5%AF%86%E7%A2%BC%E8%A8%AD%E5%AE%9A)

1. 前往 [Google 帳戶安全性](https://myaccount.google.com/security)
2. 啟用「兩步驟驗證」
3. 前往 [應用程式密碼](https://myaccount.google.com/apppasswords)
4. 生成密碼並填入 `.env` 的 `EMAIL_PASS`

## 注意事項

[Permalink: 注意事項](https://github.com/911218sky/openai-register#%E6%B3%A8%E6%84%8F%E4%BA%8B%E9%A0%85)

1. 建議使用穩定的代理服務
2. 設定合理的等待時間（15-60 秒）避免 IP 被封
3. 不要將 `.env` 和 `config.yaml` 提交到版本控制
4. 本工具僅供學習和研究使用

## 常見問題

[Permalink: 常見問題](https://github.com/911218sky/openai-register#%E5%B8%B8%E8%A6%8B%E5%95%8F%E9%A1%8C)

**Q: 為什麼需要 Gmail 應用程式密碼？**

A: Gmail 安全政策要求使用應用程式密碼存取 IMAP。

**Q: 可以不配置 IMAP 嗎？**

A: 可以，程式會提示手動輸入驗證碼。

**Q: 註冊失敗怎麼辦？**

A: 檢查代理、使用 `-d` 查看日誌、確認 IMAP 配置、增加等待時間。
