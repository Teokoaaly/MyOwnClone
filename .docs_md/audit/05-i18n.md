# Auditoria 100% - i18n y Contenido (2026-06-11)

## Resumen

- **Estado:** Amarillo/Rojo.
- **Riesgo principal:** el producto mezcla ingles y espanol, mientras el clone tiene idioma propio.
- **Veredicto:** no bloquea la arquitectura, pero si bloquea una experiencia profesional.

1. Definir idioma base inicial: espanol para dashboard o ingles para SaaS global.
2. Usar keys internas no traducidas (`basic`, `pro`, `scale`) y labels traducibles.
3. Crear namespaces: `dashboard`, `billing`, `settings`, `chat`, `landing`, `errors`.
4. Migrar primero sidebar, billing y public chat.
