## Claim

La Web Data API de Decodo incluye un **plan gratuito permanente** con **"$5 in testing credits (up to 10k requests) with no credit card required to get started"**. El banner de la home y el FAQ lo repiten: "You can start using Web Data API with a free starter plan without a credit card. Sign up, test your requests, and upgrade when you need more capacity". Esto contrasta con la línea residencial, que ofrece solo una **prueba de 3 días con 100 MB** que **auto-activates el plan de pago** al terminar.

## Why It Matters

El vault ya registró que en Bright Data el captcha se reabsorbe en el precio del tráfico, y que el PAYG de Decodo existe para quien quiere granularidad y no suscripción. El plan gratuito permanente de la API **agrega un tercer modelo de entrada** —sin tarjeta, sin trial caducado, uso ilimitado dentro de los 10K requests. Para usuarios con flujos de trabajo intermitentes, esto es **menor fricción que un trial de 3 días que requiere tarjeta y auto-activación**, y diferente al modelo de precompra de GB de otros proveedores.
