## Claim
Los tres repositorios que concentran el 94 % de las estrellas del corpus son **tres objetos de naturaleza distinta**, y solo dos de ellos son describibles con la captura. `verssache/chatgpt-creator` (338 estrellas, 90 forks, Go, MIT, `created_at` 2026-03-10, `pushed_at` 2026-04-06) es **un bot de registro en un solo lenguaje**, con descripción en inglés y tamaño de repositorio de solo **24 KB** —el más pequeño de todo el corpus—; el vault ya lo había atomizado como script de nueve pasos sin teléfono ([[2026-1024-chatgpt-creator-bot-go-de-registro-masivo-de-cuentas-de-chatgpt]]). `AuuCoder/gptGrok2api` (285 estrellas, 145 forks, Python, MIT, 4.863 KB) es **un gateway**: su descripción bilingüe declara, en la parte china, una máquina de registro de ChatGPT y de Grok con **registro totalmente por protocolo, soporte de OAuth, recepción de códigos por correo, pool de cuentas, rotación de proxy y API compatible con OpenAI y Anthropic**, y repite en la parte inglesa que es un "GPT/Grok Account Creator & API Gateway with automated registration, email verification and proxy rotation", y es el único con homepage de negocio ([[2026-1024-gptgrok2api-gateway-unificado-gpt-y-grok-en-api-compatible]]). El tercero, `wahdalo/chatgpt-account-creator` (139 estrellas, 69 forks, JavaScript, MIT, 98 KB), **no es describible desde esta captura**: su `description` es `null`, no publica topics, no tiene homepage y `created_at` y `pushed_at` están separados por **22 minutos**. Es el tercer repo más popular del corpus y el vault **no sabe qué hace**.

## Why It Matters
Este átomo marca el **límite exacto de lo que la API de búsqueda permite concluir**, y tiene tres consecuencias concretas.
La primera: **139 estrellas no son una categoría, son un agujero**. El vault tiene átomos sobre el primero y el segundo —un bot y un gateway— y nada sobre el tercero, que sin embargo tiene casi la mitad de las estrellas del primero. Cualquier afirmación del vault del tipo "la herramienta open source de referencia para registrar cuentas de ChatGPT" sería falsa si se apoya solo en estrellas: el tercero pesa casi lo mismo y es invisible. La captura **no permite** decir que `wahdalo` sea mejor, peor, ni comparable.
La segunda: **el tamaño y la fecha delatan la forma del proyecto**. 98 KB con `pushed_at` 22 minutos después de `created_at` es la firma de un repositorio subido de una vez; y 24 KB para el bot de 338 estrellas dice lo mismo. El corpus, medido por tamaño, tiene **tres órdenes de magnitud de distancia** entre el bot de un archivo y el gateway multi-módulo — lo que sugiere que la categoría no tiene un único tipo de artefacto.
La tercera, y es la que conecta con el thread: **el corpus separa "registro" de "operación de capacidad"**. El bot produce cuentas; el gateway además las **gestiona** (pool, proxies, logs, cuota) y las **vende como capacidad** vía API compatible. Es exactamente el salto que la thread viene describiendo entre la capa (b) account-farming y la capa (c) relay de acceso ([[2026-1023-lzt-categoria-llm-accounts-para-reventa]]). El JSON no lo dice, pero la comparación de lo que sí dice lo deja ver: **el segundo escalón de la categoría ya no es la herramienta, es el servicio**.
