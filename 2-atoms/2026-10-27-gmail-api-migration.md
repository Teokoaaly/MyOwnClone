## Claim
The Gmail API is suitable for email account migration between services or systems.

## Why It Matters
Migration is a common enterprise need; the Gmail API provides the programmatic access required to move messages, labels, and thread structures from one system to another.

## [FRICTION]
> [[2026-10-27-gmail-api-uses]] (escrita hoy) afirma que la API cubre migración de cuentas. Esta nota presiona eso porque la migración puede involucrar cambios de proveedor completos, no solo transferencias dentro de Google Workspace. Ambas no pueden ser completamente correctas.
