## Claim
No uses inboxes.com para información importante como banking, compra de criptomonedas o servicios que usas a diario: estos buzones son solo para registros en sitios web que no confías.

## Why It Matters
El vault categoriza los servicios de email temporal como insumos desechables de bajo riesgo, no como infraestructura crítica. Si usas un buzón desechable para banking o crypto, pierdes acceso de recuperación cuando el buzón expire o el dominio se recicle. El modelo de seguridad asume que el email de recuperación debe ser permanente y vinculado a tu identidad, no desechable.

## [FRICTION]
> [[2026-1024-notletters-correo-masivo-para-registros-y-lolzteam]] promociona su servicio precisamente para "registros masivos" y sitios como Lolzteam, donde la intención es crear múltiples identidades temporales. Este átomo prescribe que usar inboxes.com para el mismo caso de uso (registros masivos) está bien, pero usarlo para banking o crypto va contra el caso de uso previsto: el servicio está diseñado para registros únicos o esporádicos, no para identidades financieras de largo plazo. Ambas afirmaciones son correctas en su contexto, pero entran en conflicto cuando el usuario aplica el servicio fuera de su caso de uso diseñado.
