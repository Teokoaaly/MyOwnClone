## Claim

MoreLogin's pricing comparison table uses yes/no/svg indicators to show feature availability across Free, Pro, and Custom plans — features real canvas fingerprint, multiple kernels, WebRTC mode, synchronizer, recycle bin, proxy management, team collaboration, batch operations, local API, and port calling WebDriver are marked yes across most tiers, with some New markers indicating recently added features.

## Why It Matters

The visual comparison matrix gives users at-a-glance clarity on what's included at each price tier, reducing research time and helping users quickly assess whether a given plan meets their required feature set without reading through lengthy feature lists.

## [FRICTION]

> The comparison matrix shows "yes" for real canvas fingerprint across Free, Pro, and Custom, but the Free plan's 2-profile limit and Pro plan's 10-profile limit create different practical values from the same fingerprinting feature — "yes" is technically correct but functionally differentiated by profile caps, which means the comparison matrix alone doesn't convey the scale-dependent utility of features, requiring human judgment to interpret correctly.
