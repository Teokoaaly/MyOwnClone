## Claim

El Premium Tier de Qdrant Cloud requiere gasto mínimo y está dirigido a enterprises con necesidades adicionales de seguridad y compliance, ofreciendo SSO, Private VPC Links, SLA 99.9% y soporte dedicado.

## Why It Matters

El Premium Tier cubre el gap entre Standard y Private Cloud para organizaciones que necesitan features de enterprise sin migrar a una despliegue totalmente dedicado. El minimum spend requirement y el soporte 24x7/365 lo hacen adecuado para cargas de trabajo críticas donde el tiempo de inactividad no es una opción.

## [FRICTION]

> [[2026-1029-qdrant-private-cloud]] (escrita hace ~21 semanas) afirma que el Private Cloud ofrece "complete control con on-premise deployment" y "custom SLAs", mientras que el Premium Tier también ofrece 99.9% SLA y soporte enterprise —la distinción entre "managed" (Premium) y "self-managed" (Private Cloud) no es binaria, ya que el Premium Tier gestiona la infraestructura bajo el plano de Qdrant mientras que el Private Cloud requiere que el usuario provea y gestione su propia infraestructura, lo que cambia radicalmente el modelo de operativa y responsibility. Ambas ofrecen SLA 99.9% pero el contexto de responsibility difiere. Marcado para juicio humano, no auto-resuelto.
