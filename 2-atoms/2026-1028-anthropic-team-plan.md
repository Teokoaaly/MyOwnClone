## Claim

The Anthropic Team plan targets teams of 2 to 150 users with two seat types: **Standard** at $20/seat/month annually ($25/month billed monthly) and **Premium** at $100/seat/month annually ($125/month billed monthly), giving Premium 5x more usage than Standard. All Team plans include all Claude features plus greater usage than Pro, Claude Code and Claude Cowork, Claude Design, Slides, and Docs, Microsoft 365 and @Claude integration, enterprise search across the organization, central billing and administration, SSO, admin controls for remote and local connectors, enterprise deployment for the Claude desktop app, mixed seat types, and up to $500/month in pooled API credits.

## Why It Matters

The Team plan bridges the gap between individual paid plans and Enterprise, offering organizations centralized management, seat management, and pooled API credits. The 5x usage multiplier on Premium seats and the ability to mix seat types provide flexibility for diverse team composition. The $500/month pooled API credits add significant value for teams with variable API usage patterns.

## [FRICTION]

> The pricing structure creates confusion between "Per seat / month if billed annually. $25 if billed monthly" for Standard and "Per seat / month if billed annually. $125 if billed monthly" for Premium — both show the same annual/monthly split but at dramatically different price points, and the annual discount rationale is not explained (annual billing typically offers 10–20% discounts, but here the monthly price is identical for both seat types regardless of billing cycle).

> Adding seats midterm is listed as "n/a" with no explanation of whether seats can be added, how pricing is adjusted, or if pro-rata billing applies. Teams discovering mid-quarter needs have no clear path to scale without contacting sales or re-evaluating the plan.

> The Premium seat's "5x more usage than standard seats" claim is relative but not anchored: 5x more than what? If Standard already includes "more usage than Pro," the compound multiplier is unclear. A team evaluating Standard vs Premium cannot compute the actual usage difference without digging into usage limit documentation.

> Enterprise search across your organization and admin controls are marketed as Team features, yet the feature comparison table under "Security and administration" shows these as "No" for Free and Pro but "Yes" for Team — creating a tiering expectation that may not match the actual capability boundaries or usage quotas enforced in practice.
