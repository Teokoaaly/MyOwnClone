## Claim
El API key introducido en Veridrop se usa únicamente para la detección actual y no se almacena en el informe ni se guarda persistentemente. Esta es una garantía de privacidad: la key no se retiene después de terminar la prueba, y no aparece en ningún reporte o registro persistente.

## Why It Matters
Los usuarios preocupados por la privacidad de su API key pueden usarla con confianza en Veridrop, sabiendo que no será almacenada ni utilizada para otros fines después de la detección. Esto contrasta con otros servicios que pueden guardar keys para fines de análisis o monetización. La captura especifica explícitamente "solo para esta detección, no se escribe en el reporte, no se persiste".

## [FRICTION]
> No hay fricción con átomos existentes: esta afirmación sobre la política de datos del API key es nueva y no contradice ninguna creencia almacenada en el vault. Es una garantía de privacidad explícita en la fuente capture, sin conflicto con notas previas.
