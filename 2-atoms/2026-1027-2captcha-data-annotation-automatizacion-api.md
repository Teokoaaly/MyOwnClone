## Claim

La página `2captcha.com/pricing/data-annotation` anuncia **automatización API-powered**: "API-powered automation that fits your process: Create fully automated data annotation workflows". Esta afirmación sugiere que el servicio no solo proporciona mano de obra humana, sino que ofrece una capa de automatización que se integra en flujos de trabajo existentes mediante API, posicionando la anotación de datos como un proceso tecnológico más que manual.

## Why It Matters

El vault ya documentó el giro de 2Captcha hacia la infraestructura de automatización [[2026-1024-2captcha-giro-hacia-scraping-y-mcp-para-agentes]], donde el mismo proveedor que vendía la elusión de captchas ahora vende Browser API, Scraper API y MCP para agentes. El salto a la anotación de datos como flujo de trabajo automatizado completa ese giro: **el modelo de negocio pasa de "resolver captchas baratos con mano de obra humana" a "vender acceso a una fuerza laboral global para anotación de datos, con automatización API como capa superior"**. La certeza es "tentative" porque la página no publica detalles técnicos sobre la API (endpoints, autenticación, límites de tasa, formato de salida), y la afirmación podría ser marketing para upsell el plan de contacto comercial en lugar de describir una capacidad técnica documentada.
