## Claim
Grok se vende como **una sola suscripción, la X Subscription** (vigente desde **2026-10-12**), en cuatro escalones con cuota expresada como **multiplo del plan Plus**, refrescada cada semana:

| Plan | Precio | Cuota |
| --- | --- | --- |
| Plus | $8/mes | 1x |
| Premium | $30/mes | 4x |
| Super | $100/mes | 15x |
| Ultra | $200/mes | 50x |

Plus incluye **Grok, Imagine (imagen), Grok Build, Cursor Agent, Grok API y X Premium** (marca azul, edición de posts,的长文). Premium añade **generación de vídeo, Grok Bot, Cursor cloud agent y automatizaciones, Origin code hosting, Bugbot code review** y uso de modelos de terceros **a precio de lista de la API**. Super añade prioridad en horas punta; Ultra, acceso anticipado a nuevos productos y modelos de xAI. Cobertura (3 ítems): **Grok 4.7, Grok 4.6, Grok 4.5**.

## Why It Matters
Es la primera fila de la tabla donde **una sola cuota cubre varios productos** (Grok + Cursor + X Premium): el mismo euro compra chat, IDE y red social. Para el vault, esto es una señal de estrategia de empaquetado del proveedor de modelos, no un detalle de precio — el caso Grok no es "suscripción de un chat" sino "suscripción de un ecosistema de herramientas de IA", igual que la tabla del ChatGPT incluye Codex ([[2026-1023-priceai-chatgpt-plus-y-pro-precios-y-ventanas]]).
También introduce una **unidad de cuota relativa** ("15x", "50x") en lugar de una cifra absoluta: un modelo de coste no puede computarse sin la definición de "1x", que la captura no publica. Compárese con las unidades absolutas de requests/prompts/credits ([[2026-1023-priceai-codificacion-por-requests-vs-prompts-vs-creditos]]).
