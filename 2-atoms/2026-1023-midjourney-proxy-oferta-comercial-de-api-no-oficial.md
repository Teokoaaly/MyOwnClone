## Claim
El propio README del proyecto de código abierto **ofrece comercialmente una API no oficial**, en una sección titulada **"开放API"**: **"提供非官方的MJ/SD开放API，添加管理员微信咨询，备注: api"** — se proporcionan APIs abiertas **no oficiales** de MJ/SD; para consultarlas hay que añadir al administrador por WeChat indicando "api". El bloque *About* enlaza además un dominio comercial, **api4midjourney.com**. En la sección de advertencias el README también invita a un grupo de WeChat (con "加管理员微信邀请进群，备注: mj加群") y pide stars al proyecto.

## Why It Matters
Esto convierte el repositorio en un **embudo de captación de clientes de un servicio comercial de API**, no solo en código abierto: la versión Apache-2.0 en GitHub es el gancho, y la monetización está en el canal privado (WeChat). Es decir, el mismo puente que se documenta como proyecto abierto ([[2026-1023-midjourney-proxy-convierte-discord-en-api-rest]]) es la infraestructura de un servicio que se cobra. Y en la otra dirección, los productos de terceros que se apoyan en este puente ([[2026-1023-midjourney-proxy-ecosistema-de-aplicaciones-que-lo-consumen]]) amplifican la superficie de esa oferta. El vault ya tiene un patrón casi idéntico en el lado opuesto del mercado: PriceAI es un **catálogo que no vende API y no promete disponibilidad** ([[2026-1023-priceai-descargo-de-responsabilidad-sin-sla]]); aquí el catálogo es un **proxy que sí opera la API, pero sin ningún SLA declarado** y con la dependencia de baneo de cuenta ([[2026-1023-midjourney-proxy-riesgo-de-cuenta-por-frecuencia-de-dibujo]]).
La lectura de negocio para el vault: **la monetización de un proxy no oficial no está en el markup del token, está en el servicio**: traducción, filtrado, pool de cuentas, panel de administración y resolución de captchas son exactamente las funciones de la edición plus ([[2026-1023-midjourney-proxy-edicion-plus-ampliada]]). El README no publica **ningún precio** de esa API: el precio está, si existe, detrás del contacto privado.
También es un recordatorio de fondo: "API abierta" aquí significa "API no oficial", no "API pública documentada".

## Nota de verificación
La captura **no contiene ningún precio, plan, SLA ni condición de la oferta comercial** de api4midjourney.com: solo la frase del README y el enlace. No hay forma de evaluar el margen de este modelo con esta fuente.
