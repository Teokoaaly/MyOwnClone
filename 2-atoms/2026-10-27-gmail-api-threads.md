## Claim
A Gmail thread is a collection of related messages forming a conversation, where one or more recipients respond to a message with their own message, creating a linked conversation history.

## Why It Matters
Thread management is central to the Gmail UI and API experience; understanding how messages group into threads enables proper conversation tracking, filtering, and notification strategies.
