## Claim
La home de 2Captcha ya no vende solo captchas: publica una **línea de scraping y datos** — Browser API (navegador automatizado con stealth y gestión de proxies), Scraper API (rotación de proxies, anti-bot bypass, renderizado JS), Browser fingerprints (perfiles reales de navegador) y **Web Unlocker** ("automatically handles blocks, captchas, and proxy rotation, **so you pay only for successful data extraction**") — más **cuatro servidores MCP** para agentes: Web MCP, Browser MCP, Web Search MCP y Web Scraper MCP, con repositorio `github.com/2captcha/2captcha-mcp`.

## Why It Matters
Es un **giro de categoría de producto**: de "resolver captchas" a "infraestructura de acceso a web para agentes de IA". Y lo hace con el mismo argumento económico que ya usa el vault para el relay: cobrar por el **resultado útil** (extracción exitosa) y no por el recurso ([[2026-1024-2captcha-solo-se-paga-por-captcha-resuelto]]).
La pieza MCP es la directamente relevante: cuatro servidores MCP publicados para conectar agentes a búsqueda, scraping y automatización de navegador es exactamente la superficie que el vault registró como **nuevo vector de ataque** ([[2026-1023-ai-security-tools-mcp-como-superficie-de-ataque]]). Que un proveedor comercial de elusión anti-bot sea a la vez proveedor de herramientas MCP para agentes confirma que la convergencia "agente = navegador que evade controles" ya tiene un proveedor de facto, y que el vault está del lado del cliente de esa oferta, no del lado del proveedor.
También es el mismo patrón de negocio que el proxy de imagen: **core abierto en GitHub + valor en la operación comercial** ([[2026-1023-midjourney-proxy-oferta-comercial-de-api-no-oficial]]).
Nota: la captura **no** publica precios de Browser API, Scraper API, fingerprints, Web Unlocker ni de los MCP; solo la tabla de captchas.

La captura de AntiCaptcha muestra **una tercera forma de resolver la misma tensión**, y es la más relevante para el vault: **el plugin de navegador gratuito** para Chrome, Firefox y Safari, que detecta los captchas automáticamente en segundo plano y **sin interacción del usuario**, integrado con **iMacros, Puppeteer y Selenium** ([[2026-1026-anticaptcha-plugin-de-navegador-gratuito]]). En ambos casos la conclusión de este átomo se mantiene —"el captcha es una commodity y quien la usa está del lado del cliente"—, pero ahora hay **dos empaques distintos** para la misma capacidad, y el que el vault elegiría para un producto propio es el que **no requiere construir una superficie de agentes nueva**.

## Nota de extensión 2026-10-27
Este átomo sitúa el giro de 2Captcha hacia la infraestructura de acceso para agentes y afirma que "el vault está del lado del cliente de esa oferta, no del lado del proveedor". La captura de `/pricing/enterprise-support` del 2026-10-26 **añade la pieza que faltaba para entender a quién se vende el giro**: la página enumera **"Support for integrating custom API solutions"** y **"Consulting from experienced account managers"** como servicios del plan enterprise ([[2026-1027-2captcha-enterprise-support-sin-precio-publico-ni-cifras]]).

**La lectura es que la oferta de agentes no se vende sola: se vende con consultoría de integración.** El producto del giro —MCP, Browser API, Scraper API— es **infraestructura con precio unitario**; el plan enterprise es **asesoría humana sin precio**. Para el cliente del vault, esto significa que la línea cotizable y la línea que de verdad habilita el despliegue (integrar el MCP en el agente, revisar el código, priorizar incidencias) son **líneas distintas y la segunda no tiene cifra**. Es exactamente la forma que el vault ya registró en la fricción 37 para Proton ("la línea de empresa es la única partida del vault cuyo precio no existe en ninguna captura"), y aquí se repite **en el proveedor del corpus que sí tiene precios públicos**.

**La consecuencia para el modelo de coste es una partida nueva, no una nueva cifra.** El vault puede cotizar el tráfico, las llamadas y los requests, pero **no puede cotizar la integración**: si el pipeline de agentes necesita que alguien integre y depure la API, ese coste entra en el modelo como **tiempo de integración no cotizado** —el mismo tipo de partida que el vault ya registra para la extensión de navegador de CapSolver, donde el coste sale de la tabla y entra en el tiempo de la persona. La línea enterprise de 2Captcha es la versión más explícita de ese fenómeno en el corpus: **el proveedor que publica 48 precios por captcha no publica el precio de su propio trabajo de integración**.

Nota de verificación: la captura **no** publica el precio del plan enterprise ni si se factura por separado del consumo.


## Nota de extensión 2026-10-27
Esta extensión **cierra la laguna que este átomo declaraba explícitamente**. Su nota decía: "la captura **no** publica precios de Browser API, Scraper API, fingerprints, Web Unlocker ni de los MCP; solo la tabla de captchas". Con las capturas del 2026-10-26 de `2captcha.com/pricing/mcp`, `/pricing/scraper-api` y `/pricing/browser-api`, **tres de esas cinco lagunas quedan cerradas con cifras**: el MCP publica **seis modos** con precio por llamada de **$0.0001** (API Tier) a **$0.0048** (Camoufox) ([[2026-1027-2captcha-mcp-seis-modos-con-precios-por-llamada]]), el Scraper API publica **$0.3 por 1.000 requests** en sus cinco planes ([[2026-1027-2captcha-scraper-api-030-por-mil-de-requests-en-los-cinco-planes]]) y el Browser API publica **$0.10/GB** con el tráfico de proxy facturado aparte ([[2026-1027-2captcha-browser-api-010-por-gb-con-el-proxy-facturado-a-parte]]).

**La consecuencia mayor para el thread es una frase de este átomo que queda desactualizada.** Su "Why It Matters" afirmaba que "la partida que el thread no tiene —infraestructura de automatización para agentes, cotizada en alguna unidad que no sea $/1000— sigue sin precio en todo el corpus". Eso ya no es cierto: **la infraestructura de automatización para agentes está cotizada, en unidades distintas y por debajo del captcha**. La unidad que apareció es la **llamada** (MCP: $0.0001 por llamada, $0.1 por 1.000 llamadas) y el **GB de tráfico de navegador** ($0.10/GB); el Scraper API sí usa $/1000 pero **por requests, no por captchas**.

**El giro queda además fechado por la estructura de precios, no solo por el marketing.** Los seis modos del MCP no son seis productos: el modo base consume **1 crédito** y el modo Camoufox consume **48**, con el precio como función lineal de los créditos (**1 crédito = $0.0001 por llamada**) ([[2026-1027-2captcha-mcp-un-credito-vale-0001-y-el-render-y-camoufox-lo-multiplican]]). Es decir, 2Captcha vende **sigilo como multiplicador de precio**, y el vault tiene por primera vez el multiplicador publicado: **48×** entre el modo más barato y el más caro.

Y hay un dato que el átomo no tenía y que reencuadra el "cobrar por el resultado útil": **el Scraper API se cobra por request, no por extracción exitosa** —misma capacidad conceptual, unidad opuesta a la del Web Unblocker ("you pay only for successful data extraction")— lo que sitúa el principio de "pagar por el resultado" como **elección de empaque por línea de producto**, no como propiedad del giro. Ver la fricción del átomo [[2026-1027-2captcha-scraper-api-030-por-mil-de-requests-en-los-cinco-planes]].

La captura del 2026-10-26 corrige la nota de cierre de este átomo: "la captura **no** publica precios de Browser API, Scraper API, fingerprints, Web Unlocker ni de los MCP". Lo que ocurre es más preciso que una ausencia: **las páginas de precios de esas líneas existen y están enlazadas desde la navegación del hub `2captcha.com/pricing`**, que ahora muestra **siete líneas** —Captcha, Proxy, Browser API, Scraper API, MCP, **Data annotation** y **Enterprise support**— cada una con su propia ruta `/pricing/<línea>` ([[2026-1027-2captcha-menu-de-precios-con-7-lineas-y-dos-sin-cifra]]).

Dos consecuencias. **Primera: la línea "Data annotation" es nueva respecto a la captura del 2026-10-23 y es un giro de naturaleza distinta**: no es evasión ni scraping, es **mano de obra humana de etiquetado** vendida como producto a clientes de IA — el mismo recurso (el trabajador humano) que 2Captcha revendía como captcha resuelto, ahora facturado como dataset. **Segunda: el MCP sí tiene precios**, con seis modos cotizados por llamada, de modo que la ausencia que este átomo registraba ya está cubierta ([[2026-1027-2captcha-mcp-seis-modos-con-precios-por-llamada]]).

El balance que queda es: **de las siete líneas del hub, el vault ya puede cotizar tres (Captcha, Proxy, MCP) y le faltan cuatro (Browser API, Scraper API, Data annotation, Enterprise support)**. El giro hacia "infraestructura de acceso a web para agentes" es por tanto **un hecho con índice de precios pero con cuatro huecos**, y el MCP confirma que la superficie de ataque MCP que el thread registró como vector tiene ya tarifa publicada. Añadido: con la línea **Proxy**, 2Captcha **deja de ser solo un proveedor de captcha y se convierte en proveedor de dos partidas del modelo de coste** —captcha por 1000 y proxy por GB— con **la misma cuenta y la misma integración**, lo que convierte la elusión completa en una factura con unidades distintas ([[2026-1027-2captcha-proxy-residencial-de-399-a-125-por-gb-en-nueve-escalones]]).
