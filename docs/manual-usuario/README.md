# Manual de usuario

## 1. Introducción

MyOwnClone permite crear un clon de IA entrenado con tu contenido para responder preguntas, organizar conocimiento, gestionar mensajes, analizar uso y conectar flujos de negocio.

## 2. Primeros pasos

### Acceso y login

1. Entra en `https://myownclone.com/login`.
2. Escribe tu email y contraseña.
3. Pulsa **Sign in**.
4. Si eres administrador de plataforma, entrarás en el panel admin.
5. Si eres usuario de workspace, entrarás en el dashboard.

### Recuperación de contraseña

1. Pulsa **Forgot your password?**.
2. Introduce tu email.
3. Abre el enlace recibido.
4. Define una contraseña nueva de al menos 8 caracteres.

## 3. Interfaz principal

Menú lateral:

- **Overview**: resumen del clon y actividad.
- **Search / Library**: contenido y búsqueda.
- **Crawl / Memory**: memoria del creador.
- **Extract / Inbox**: triage de emails.
- **Research / Products**: productos o catálogo.
- **Usage**: analíticas.
- **Plans**: selección o upgrade de plan.
- **Billing**: balance, historial, portal Stripe.
- **Settings / API Keys / Team Settings**: configuración.

## 4. Funcionalidades principales

### Crear o revisar tu clon

1. Entra en **Overview**.
2. Revisa el estado del clon activo.
3. Si falta configuración, completa onboarding.

### Subir conocimiento

1. Entra en **Library** o **Crawl**.
2. Añade fuentes o memorias.
3. Espera a que el sistema procese el contenido.
4. Prueba una pregunta en el chat.

### Cambiar de plan

1. Entra en **Plans**.
2. Revisa tarjetas y características.
3. Pulsa **Select plan** en el plan deseado.
4. Completa checkout en Stripe.

Nota: **Billing** no es para elegir planes; Billing es para pagos, portal, saldo e historial.

### Ver facturación

1. Entra en **Billing**.
2. Consulta balance efectivo, cash, voucher, crédito y outstanding.
3. Abre el portal Stripe si está disponible.
4. Revisa historial de pagos o vouchers.

## 5. Casos de uso frecuentes

- Publicar un clon básico: configura clon, añade conocimiento y prueba chat.
- Mejorar respuestas: añade memoria específica y ejemplos.
- Pasar a plan superior: abre **Plans** y selecciona plan.
- Revisar gasto: abre **Billing** y **Usage**.

## 6. Gestión de perfil

Desde **Settings** puedes revisar preferencias del workspace. Para cambios de email, roles o acceso, contacta con el administrador.

## 7. Roles y permisos

- Usuario workspace: gestiona su clon y datos.
- Admin workspace: gestiona configuración y equipo.
- Platform admin: accede a panel global de tenants, feedback, auditoría e impersonation.

## 8. Buenas prácticas

- No subas contenido sensible si no debe ser usado por el clon.
- Mantén fuentes actualizadas.
- Prueba respuestas después de cambios importantes.
- Usa **Plans** para upgrades y **Billing** para pagos/historial.

## 9. FAQ

**No puedo entrar.** Borra cookies de `myownclone.com` o usa ventana incógnito. Si sigue, pide reset de contraseña.

**Veo 401 en consola.** Suele ser sesión caducada. Cierra sesión y entra otra vez.

**No veo planes.** Puede que Stripe o los planes no estén configurados para tu tenant.

**El chat no responde.** Revisa si el clon está publicado y si hay contenido entrenado.

## 10. Problemas comunes

| Problema | Qué hacer |
|---|---|
| Login no avanza | Recarga, borra cookies y vuelve a entrar. |
| Upgrade abre Billing | Usa el menú **Plans**; si sigue pasando, reporta bug. |
| Pago no aparece | Abre portal Stripe o contacta soporte con fecha e importe. |
| Respuesta incorrecta del clon | Añade memoria/fuente más precisa y vuelve a probar. |

## 11. Soporte y contacto

Contacto operativo: `hello@myownclone.com`.

Incluye siempre:

- Email de cuenta.
- Ruta donde ocurre el problema.
- Captura o texto del error.
- Hora aproximada.

## 12. Glosario

- Clone: asistente IA entrenado con tu contenido.
- Plan: nivel de suscripción.
- Billing: facturación, saldo e historial.
- Tenant/workspace: espacio de trabajo de una empresa o creador.
- Voucher: crédito promocional para consumo.
