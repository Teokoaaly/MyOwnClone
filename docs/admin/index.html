Arquitectura

Mapa de producción

Next.js actúa como consola web y proxy autenticado; Flask mantiene la lógica de negocio y los servicios internos.

Frontend

MyOwnClone/: Next.js 16, App Router, React 19, Tailwind v4, NextAuth 5.

Backend

api/: Flask, SQLAlchemy, Alembic, API console y API pública SSE.

Datos

PostgreSQL con pgvector, Redis y Weaviate. No se deben versionar dumps ni secretos.

Restore

Restaurar desde GitHub

Esperando VPS nuevo

El VPS anterior ya no existe, así que la recuperación debe hacerse sobre una máquina nueva o una IP nueva. Flujo recomendado:

git clone https://github.com/Teokoaaly/MyOwnClone.git /opt/myownclone/source
cd /opt/myownclone/source
git checkout audit/vps-sync-and-docs
sudo bash ops/restore-from-github-on-vps.sh

Antes de ejecutar, crear los archivos reales de entorno en /opt/myownclone/shared/. No copiar secretos al repositorio.

Checklist

Validación post-deploy

  1. 1
    Servicios

    Comprobar Docker, systemd frontend, Nginx y certificados TLS.

  2. 2
    Auth

    Validar login usuario y admin sin bucles hacia login ni 401 en APIs frontend.

  3. 3
    Planes

    Confirmar que upgrade abre /planes y checkout, no /facturacion.

  4. 4
    Billing

    Confirmar portal, balance e historial sin mezclar selección de plan.
