Capítulo 1

Visión general

MyOwnClone es una plataforma SaaS multi-tenant para crear clones IA con chat público, modos de respuesta, memoria del creador, email triage, booking, productos, analíticas, billing e impersonation de administración. Next.js actúa como consola web y proxy autenticado; Flask mantiene la lógica de negocio y los servicios internos.

Next.js 16 Flask 3 PostgreSQL + pgvector Redis Weaviate Stripe Resend

Capítulo 2

Arquitectura

El navegador llega a Nginx (HTTPS). Next.js sirve la consola y hace de proxy autenticado hacia Flask. Nginx también enruta directamente a Flask las APIs nativas del backend. Flask habla con PostgreSQL, Redis, Weaviate y los proveedores externos.

Capítulo 6

Rutas y proxy

Crítico · fuente del 401

La separación de rutas es lo más delicado del despliegue. Las rutas que deben leer la cookie de NextAuth tienen que pasar por Next.js para que proxy.ts adjunte las cabeceras X-API-Key e identidad. Si Nginx las manda directo a Flask, devuelven 401.

RutaDestinoMotivo
/api/clone/*Next.js → proxyLee cookie NextAuth y añade cabeceras service-to-service a Flask.
/api/admin/*Next.js → proxyEvita bucles de admin y conserva la sesión del navegador.
/api/auth/*Next.jsNextAuth catch-all.
/api/myownclone/*FlaskAPI de negocio canónica y rutas públicas de chat.
/console/*FlaskConsole API histórica del backend.
/planes · /facturacionNext.jsSelección de plan y billing (páginas, no API).
Incidente 401

Si /api/admin/* o /api/clone/* devuelven 401, revisa que Nginx las enrute vía Next.js (plantilla ops/nginx.myownclone.conf.example) y no directo a Flask.

Despliegue

Layout en el VPS bajo /opt/myownclone:

Ruta VPSQué contiene
/opt/myowncloneRaíz de la app.
/opt/myownclone/currentSymlink a la release activa.
/opt/myownclone/releases/<id>Snapshots desplegables.
/opt/myownclone/shared/*.env.productionEnv real (frontend y backend), no versionado.

Frontend

bash ops/deploy-frontend.sh

Backend

bash ops/deploy-backend.sh

Nginx

sudo cp ops/nginx.myownclone.conf.example /etc/nginx/sites-available/myownclone
sudo ln -sfn /etc/nginx/sites-available/myownclone /etc/nginx/sites-enabled/myownclone
sudo nginx -t
sudo systemctl reload nginx

Capítulo 12

Seguridad operativa

Hallazgos reales
Auth dual

Dos capenas: NextAuth JWT (frontend) y Flask JWT/service headers (backend). login_required acepta Bearer JWT o cabeceras service-to-service.

Bug bcrypt/systemd

PLATFORM_ADMIN_PASSWORD_HASH no puede ir en .env.production (dotenv expande $ del hash). Cargarlo vía systemd EnvironmentFile.

Nginx crítico

/api/admin/* y /api/clone/* deben pasar por Next; si van directo a Flask, 401.

Headers TLS

HSTS, X-Frame-Options, nosniff y Referrer-Policy presentes. Falta CSP versionado.

Service key

Validar ALLOW_DEV_SERVICE_KEY=false en producción.

Higiene

Nunca commitear .env; permisos 0600; rotar tokens de accesos temporales.

Capítulo 14

Backups y rollback

Automatización pendiente (P1)

Backup manual Postgres:

docker exec myownclone_postgres pg_dump -U postgres myownclone | gzip > myownclone-$(date +%F).sql.gz

Rollback frontend (release anterior):

ln -sfn /opt/myownclone/releases/<release-anterior> /opt/myownclone/current
systemctl restart myownclone-frontend

Capítulo 17

Restaurar desde GitHub

Esperando VPS nuevo

El VPS anterior fue eliminado, así que la recuperación se hace sobre una máquina o IP nueva:

git clone https://github.com/Teokoaaly/MyOwnClone.git /opt/myownclone/source
cd /opt/myownclone/source
git checkout audit/vps-sync-and-docs
sudo bash ops/restore-from-github-on-vps.sh
Antes de ejecutar

Crear los archivos reales de entorno en /opt/myownclone/shared/. No copiar secretos al repositorio.
